# 王一瑾的个人主页

个人作品集网站，展示游戏设计、数据分析、创意写作等领域的作品。

## 网站地址

https://yijinwang-gin.github.io


## 技术栈

- [Jekyll](https://jekyllrb.com/) 静态网站生成器
- [Hydejack](https://hydejack.com/) v9 主题
- GitHub Pages 托管

## 本地运行

```bash
# 安装依赖
bundle install

# 启动本地服务
bundle exec jekyll serve
```

访问 http://localhost:4000 预览网站。

## 目录结构

```
├── _config.yml      # Jekyll 配置
├── _data/           # 数据文件
├── _pages/          # 内容页面
├── _sass/           # 自定义样式
├── assets/          # 图片、视频、PDF 资源
├── index.html       # 首页
├── about.md         # 关于页面
├── cv.md            # 简历页面
└── posts.md         # 作品集导航
```
